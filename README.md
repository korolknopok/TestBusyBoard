# Busyboard — тестовое задание

Верстка страницы «Заявки на поставку» по макету Figma + онбординг по разделу (4 шага, циклический, закрывается только по крестику).

Бэкенда нет — все данные на странице статичные (моки).

## Что сделано

- Хэдер (лого, избранное, вкладки навигации, орг-дропдаун, иконки, аватар)
- Страница «Заявки на поставку»: панель фильтров, таблица заявок, кастомная пагинация
- Онбординг на react-joyride: 4 шага с подсветкой конкретных элементов, зациклен (после последнего шага снова первый), закрывается только по крестику

## Стек

- React 18 + TypeScript, Webpack 5, react-router-dom, Ant Design, SCSS, classnames, react-joyride

## Запуск

```bash
npm install
npm start
```

Откроется `http://localhost:3000`.

## Структура (FSD)

```
src/
  app/        — точка входа, провайдеры, глобальные стили
  pages/      — страница «Заявки на поставку» и её части
  widgets/    — хэдер
  features/   — навигация по вкладкам, онбординг
  shared/     — иконки, переиспользуемые UI-компоненты, типы
```
